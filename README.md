# Skill Grok : agriculture-benin

**Analyste stratégique et conseiller technique de très haut niveau** spécialisé dans les filières agricoles du Bénin et d’Afrique de l’Ouest.

Ce skill produit des analyses de niveau cabinet de conseil / direction stratégique :
- Diagnostic quantitatif approfondi
- Économie de filière
- Scénarios et analyse de sensibilité
- Recommandations priorisées

## Structure

```
SKILL.md                    # Instructions principales du skill
references/
├── canevas-analyse.md      # Canevas obligatoire pour notes stratégiques
├── filieres-cles.md        # Repères quantitatifs filières Bénin
├── modele-article.md       # Canevas article de vulgarisation
├── rotation-sujets.md      # Guide rotation veille quotidienne
├── sources-officielles.md  # Sources données officielles
└── veille-sources.md       # Sources de veille agro
```

## Utilisation avec Grok

Placez le dossier dans `~/.grok/skills/agriculture-benin/` (ou `/home/workdir/.grok/skills/` selon l’environnement).
